# Игровое меню Panopticon Hub

Установленный Steam Garry’s Mod загружает `html/menu.html` штатным Chromium. Адаптер интерфейса находится в `source/html/panopticon`. Вступление начинает воспроизводить локальный WebM после стабилизации кадров игрового меню. Кадры со звуком находятся в одном файле. После появления логотипа выводится локализованное предупреждение. По окончании вступления, клику или пробелу кадр гаснет, и меню проявляется из чёрного. Ролик пересобирается из исходных логотипов и звука через `tools/render-intro.py`.

`html/panopticon/entry.js` использует вызовы `stMenu` через штатный `lua.Run`. Адаптер загружает `lua/bin/gmsv_panopticon_native_win64.dll` через MENU `require`. Rust разбирает каталог, читает состояние меню, запускает команды GMod и открывает ссылки через Steamworks. Lua связывает Chromium со штатными HTTP-запросами, опросом серверов и подключением к ним. Подтверждение выхода вызывает `QuitNoConfirm`.

Кнопка проверки микрофона запускает штатный тест Source через `IVoiceTweak` в главном меню. Движок проигрывает голос локально и отдаёт уровень для индикатора. Ползунок меняет штатную громкость передачи микрофона. Тест останавливается при закрытии настроек, переходе к игре и выключении из интерфейса.

В каталоге Panopticon Trial доступны основное лобби и четыре игровых слота. Их статус движок проверяет при запросе. Типы серверов Shinri Trial приходят из публичного каталога проекта. Если каталог Shinri недоступен, движок опрашивает опубликованные адреса и показывает ответы. При возврате из Shinri в Panopticon активируется регион СНГ. Выбор Global у Panopticon сообщает об отсутствии серверов в этом регионе.

В главном меню и в меню по Esc можно выбрать язык Garry’s Mod по штатному флагу. Выбор сохраняется в `gmod_language`. Тексты меню Hub поддерживают русский, английский и французский, а для остальных языков используют английский.

Экран подключения Hub показывает номер текущего файла, когда движок сообщает его для очереди загрузок. При подготовке карты, запуске Lua и других стадиях без измеримой очереди отображается статус. Настройка «Интерфейс → Общее → Экраны загрузки серверов» разрешает `sv_loadingurl` только в сеансе Hub. По умолчанию Hub использует свой экран. Штатный `cl_enable_loadingurl` сохраняет собственное значение.

Рядом находится отдельная настройка «Штатный индикатор загрузки». По умолчанию Hub скрывает окно прогресса GMod в правом нижнем углу. Esc отменяет подключение и со скрытым индикатором.

До окончания вступления нативный фон меню чёрный. После вступления Garry’s Mod меняет кадры из `source/html/panopticon/backdrops` штатным механизмом. Рабочий процесс запуска применяет адаптер к локальному `lua/menu/background.lua` на время сеанса и восстанавливает исходный файл при выходе. В окне Hub ход запуска показывает индикатор с логотипом. Исходный Lua-адаптер находится в `source/lua/menu`. Проверка моста через Steam LuaJIT описана в основном README.
